# Story 02 原創合成音效 v1

依使用者「在關鍵場景加上音效」要求製作，取代第一輪的無聲占位設定。
全部由本專案的 [build_story02_audio.py](../../scripts/build_story02_audio.py) 使用正弦波、濾波雜訊、包絡與延遲合成，沒有網路下載、第三方錄音、樂曲或取樣，也不需要外部素材署名。
這是原創合成版本，並非另有音效師交付的實景錄音；將來可依聽感替換同一 ID 的檔案。

| ID | 內容與出現時機 | 長度 |
| --- | --- | --- |
| forest-evening | 低音量風聲、稀疏鳥鳴／蟲聲；山路與屋外。 | 20 秒循環 |
| creepy-house | 爐火沙沙聲、輕微木屋嘎吱；線索、鑰匙與躲藏。無虎吼，不提前洩露身份。 | 20 秒循環 |
| bamboo-chase | 竹葉風聲與輕腳步節奏；竹林與木橋。 | 20 秒循環 |
| temple-night | 空曠夜風與柔和長音；古廟。沒有可辨識鈴聲暗示鉤子。 | 20 秒循環 |
| found-item | 短促柔和亮音；找到線索、鑰匙或山神鈴。 | 0.46 秒 |
| success | 三個柔和上行音；三線索找齊、挑戰完成、普通結局。 | 0.96 秒 |
| fail-soft | 柔和下降短音；晃動重試、竹林碰撞。 | 0.42 秒 |
| drag-lock | 輕扣聲；山神鈴正確放上鈴鉤。 | 0.46 秒 |
| secret-bell | 一聲古銅鈴與回音；只有成功拖鈴後播放。 | 3.90 秒 |

格式：22,050 Hz、mono、PCM16 WAV；9 檔合計約 3.80 MB。
每檔的精確大小、SHA-256、峰值與 RMS 記於 [manifest.json](assets/audio/manifest.json)。合成隨機種子固定為 20260928。

## 播放規則

- 仍需第一次按「開始冒險」才建立／解鎖 AudioContext；封面不自動發聲。
- 短音效解鎖後預載，僅事件發生時播放；預載不代表先播放，也不洩漏鈴的位置。
- 環境音同時只有一條、淡入淡出；每種音效音量由 story.json 設定。躲藏時背景再降為一半。
- 神鈴播放時降低古廟環境音；按「繼續」進神光畫面仍保留同一次鈴聲，不重播或突然切斷。離開該結局、靜音、進背景會停止。
- 一般場景離開時取消尚未載入完成的 SFX，避免遲到音效跑到下一幕。
- 普通結局播放成功音並淡出背景；持有但未使用山神鈴不會發出祕密音效。
- 🔊／🔇 使用原共用偏好，已選靜音不會被更新版本覆蓋。音訊失敗仍可完整通關。

## 重建與驗證

```sh
python scripts/build_story02_audio.py
python tests/story_02_audio_test.py
```

需要 NumPy、SciPy；產出的網站本身不依賴 Python 或上述套件。
測試包含 PCM 有效性與非靜音、峰值／首尾包絡、瀏覽器解碼、Analyser 非零輸出、遊戲事件、快速按繼續、靜音與重新整理。
這些是客觀輸出驗證，不等於已在實體平板喇叭人工試聽；音量與音色仍以使用者平板回饋調整。
