2026-09-29：依使用者確認製作。三道門共 20 題，10 題加法、10 題減法，範圍均在 10 以內。

## 列印檔

- [孩子練習紙 math10-v1.pdf](math10-v1.pdf)：A4 直式三頁，每頁一道門，題數 6／7／7。
- [家長解答 math10-v1-answers.pdf](math10-v1-answers.pdf)：獨立一頁，包含 20 題答案、三組密碼及列印說明。請勿混在孩子練習紙中。

選擇 **A4、直向、單面、實際大小／100%**；黑白即可，不使用多頁合印。若印表機另作縮放，格子實體尺寸會改變，後續掃描仍須重新確認定位。

每題右側的 **28 × 28 mm** 方格就是一格密碼，從上往下按題序寫，一格一個數字，不需再抄成另一串。字寫在格子中間，與邊框留一些空白；筆跡清楚即可。沒有剩下時寫 0，不留空格。

圓點可輔助點數：加法兩群合起來，減法保留完整圓點，由孩子自行劃掉要拿走的數量。答案格內沒有提示數字、題號、底紋或答案。

## 後續鏡頭定位

- 四個實心方塊標示答案欄邊界；右上 QR 只含 `aton|story-03|math10-v1|gate-N`，沒有答案，也不是需要另開的網頁。

- [math10-v1.json](math10-v1.json) 保存題卷版本及題目。換題／換版面須同步更新題卷、PDF、定位資料與未來故事設定。

## 字型與重建

中文以使用者的 `BpmfGenRyuMin-H.ttf` 在本機渲染為高解析文字圖，保留右側注音；PDF 不嵌入或附帶字型。算式、數字、框線和定位圖形使用向量繪製，列印保持清楚。

```sh
python scripts/build_story03_worksheets.py --font "/private/path/BpmfGenRyuMin-H.ttf" --out stories/story-03/worksheets
```

需要 Pillow、ReportLab。字型路徑指向本機原檔，不能複製或 commit 字型。重建後依 PDF 流程重新檢查四頁，特別注意新中文的多音字。
