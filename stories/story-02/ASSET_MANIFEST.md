# Story 02 資產需求與交接清單

依據：[STORY_SPEC.md](STORY_SPEC.md) v1.0。狀態：**全部待交接**；本文件是需求清單，不是成品清單。表中檔名為建議命名，尚無對應圖片或音檔。

## 1. 交接欄位與責任

線上 ChatGPT／使用者提供圖片、文字與音效來源及內容確認；Codex 接收後核對檔案、尺寸、引用路徑與互動位置。每件成品交接時補上：

| 欄位 | 填寫內容 |
| --- | --- |
| Asset ID／Scene ID | 與下表及 STORY_SPEC 對應，保留 `06B`、`09A`、`09B` 等分支標記。 |
| 實際相對路徑 | 相對於 `stories/story-02/`；大小寫與實際檔案一致。 |
| 格式、尺寸、大小 | 圖片寬高／比例／透明度，音訊時長／檔案大小。 |
| 來源與授權 | 原創／生成工具或素材來源、可用與公開再散布依據、需要的署名。 |
| 版本與確認狀態 | 使用者是否確認外觀與圖文一致性；未確認不可標成可發布。 |
| 點位與安全區 | 以原圖為基準的百分比 `x/y/width/height`、物件邊界及不得遮擋區域。 |
| 替代文字／對應正文 | 與確認稿一致；有改字需求先回內容端確認。 |

圖片以約 `1055 × 1491` 的直向比例為基準，保留原比例、文字及操作安全區。插圖不烘焙文字或 UI；隱藏物件不烘焙發光、箭頭或答案提示。所有點位待實際圖稿後填寫，不預造座標。

## 5. 注音與介面文字

- 預定位置：`assets/text/text.json` 與對應透明 PNG；本次尚未建立文字 manifest 或產圖。
- 正文原文以 `STORY_SPEC.md` 為準，涵蓋 Cover、01～09、分支及線索揭露文字。
- 補齊挑戰開始／說明、兩級找物提示、成功／失敗／重試、普通 8 秒替代倒數、左右按鈕、繼續、音效開／關、返回首頁與重玩文字。未在確認稿中寫出的完整操作文案待內容交接。
- 使用 [共用產字工具](../../scripts/README.md) 與 `BpmfGenRyuMin-H.ttf`，全部兒童可見中文保持右側注音；原字型不得放入專案。
- 交接純文字、文字圖、讀音／輕聲確認與可存取名稱；產出的字圖需檢查注音與聲調邊界。
