# Story 03 工程規格 v1

2026-09-29，依使用者確認的故事方向、三門二十題、動態列印、固定題卷碼及分層素材更新。本文件取代草案中「固定題卷、不做隨機」及單張合成插畫的舊安排；故事教育點和雙結局保留。

## 故事與學習

《阿通與星光寶箱》：阿通與小松鼠前往老星塔，解開三道門，找到星燈種子，帶回森林恢復指路燈。數學為 10 以內加減；20 題全部參與密碼，10 加／10 減，三關分別 6／7／7。第一版每格一位數，答案 0–9，減法被減數可為 10；答案為 10 的題型需日後增加格子與掃描驗證。

| 場景 | 內容與選擇 |
| --- | --- |
| cover | 題卷準備、列印、開始。 |
| intro | 森林星燈不亮，前往星塔。 |
| gate1 | 第一頁六題；全對開門，等待繼續。 |
| passage | 跟隨螢火蟲進入通道。 |
| gate2 | 第二頁七題；全對開門，等待繼續。 |
| window | 一般路線上樓；長椅下星形木片可探索，不發光、不預告。 |
| gate3 | 第三頁七題；全對開門，等待繼續。 |
| chest | 打開寶箱、取得種子，等待繼續。 |
| roof | 可帶種子回森林；有木片時可自行拖入星形凹槽，保留並發光。 |
| ordinary | 星燈恢復，完整成功；有木片但沒用也能進入。 |
| secret → secret-home | 星座亮起，再帶種子回森林完成主線。 |

玩家文字以 `story.json` 為準，均預渲染注音。沒有 Game Over、計時、答錯重置整頁或自動收走成功訊息。空白不等於 0，錯題只標記，其他輸入保留。背包沒有未獲得道具的空格。

## 題卷碼與永久對應

共用 `engine/math-worksheet.js` 的 `story03-math-v1`。英數碼正規化為小寫，長度 1–24；例如 `5a2vgas12` 在所有時間／裝置固定同 20 題、題序與密碼。日期、瀏覽器與存檔進度都不參與出題。新題卷才取新碼，列印／重新整理／再玩不換題。

**v1 出題演算法發布後不可改結果。** 日後變更題池／亂數／分組須新增版本與明確格式（例如額外版本前綴），保留所有未帶前綴的現有碼使用 v1；不能用新版預設偷偷解讀舊碼。測試固定範例完整 20 題作相容性基準。

網址 `?code=...` 可分享；`print.html?code=...` 從同一模組重新產生題卷，不讀寫遊戲進度。已有進度時換碼須確認；另一個分頁換碼時提示重新開啟，避免誤寫舊卷。

## 列印

三頁 A4 直向，每頁題卷碼、道門名稱、算式、計數圓點、28 mm 空白答案格與四角定位方塊。減法不預先劃線；由孩子劃掉。孩子頁沒有答案，解答另以 `mode=answers` 開啟。中文為注音文字圖；算式的運算符號用向量圖形，避免 PDF 字型子集漏印。

先前 `worksheets/math10-v1.pdf` 是固定範例紙，保留歷史用途；它沒有新題卷碼，不能直接與新網頁密碼配對。新故事應從網頁列印帶碼的版本。掃描定位尚未實作，定位方塊不是辨識成功的證據。

## 架構與狀態

- `engine/math-worksheet.js`：純出題與核對；版本相容契約。
- `engine/scene-layers.js`：底圖／人物／道具按同一座標分層。
- `app.js`：Story 03 流程、門、道具、回饋。
- `state.js`：驗證場景、題卷、20 格輸入、三門、道具與結局。
- `print.js` / `print.css`：瀏覽器列印、分開解答。
- `text.js` / `story.json` / `assets/text/`：統一注音。
- `assets/images/`：場景底圖、透明人物與門／寶箱狀態。

存檔僅 `adventure.story-03.state`；含版本、code、scene、entries、solved、wood、seed、placed、scale。再玩只重置本故事，保留同碼；音效共用 `adventure.settings.sound`。拒絕儲存時仍可玩並提醒記下題卷碼。

重用既有 storage、AudioManager、bindDrag，不改月光洞或 Story 02。只引用 Story 02 已有原創操作音效，尚未加入第三本背景音；後續背景音遵守低音量和場景特色方向。
