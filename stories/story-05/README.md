第一關 A–I 看大寫、不限時；第二關 J–R 選小寫、12 秒；第三關 S–Z 混合大小寫、10 秒。每關先學再練，發音完才計時，可重聽／提示／關倒數；26 個字母都需點過。畫面內答題，燈逐盞亮、霧漸退，預留全螢幕與注音。

答題字母上下左右漂移，逐關加快；張嘴伸手的納別奇也飄動，點到它算一次可重試的失誤。怪物不能蓋住答案，學習與重播不移動，家長可改慢速／停止移動。此方向已寫入規格，動畫與觸控尚待工程；淨化模式照／點怪物仍是正確動作。

普通結局平安回村；祕密路線取出第一本的月亮石，拖月光圈照同一隻納別奇五輪，最後淨化成小天使。直接玩這一本也可進祕密路線，不依賴或修改第一本存檔。

尚缺：遊戲工程、字母名稱錄音、背景音樂／音效、注音文字圖、平板測試與正式發布。圖片就緒後先讓使用者確認造型／場景，再進 `feature/story-05-foundation`。
