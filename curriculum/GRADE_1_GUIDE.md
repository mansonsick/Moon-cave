# 一年級故事與練習設計依據

整理日期：2026-09-29。適用臺灣國小；目前先整理小一上，保留小一下的後續範圍。查核來源與可直接使用的教材見 [SOURCES.md](SOURCES.md)。

## 1. 已確認的方向

- 使用者尚不確定未來採用哪家課本，採康軒、翰林、南一的**知識點聯集（OR）**，不只取共同項目。
- 孩子目前還沒上小一。範圍可以廣，但每次故事從已理解的能力開始，逐步加入新內容。
- 順序為小一上 → 小一下 → 逐年擴充到小六。本次只完成資料與設計依據，沒有開始第三本的情節、圖片或工程。
- 保留大圖、短句、右側注音、觸控操作、提示與重試；已完成的兩本故事維持現狀。

## 2. 怎麼讀這份資料

「聯集」指跨版本收集學習主題和呈現方式，並非要求孩子一次學完，亦非逐字收錄所有出版社課文、生字表或題庫。這一版交叉查核官方領綱、114 學年度學校公開計畫及目前可讀的學習平台；尚未逐冊核對全部 115 學年度教材。版本、週次與特定生字仍須在實際選題時再查。

| 層次 | 本專案的使用方式 |
| --- | --- |
| 官方課綱 | 確認學習階段、年級和範圍界線。 |
| 出版社／學校課程計畫 | 確認上、下學期的實際安排及各版本內容。學校計畫代表該校安排，不代表全臺統一週次。 |
| 學習平台 | 找可觀看、操作或練習的資源；「類康軒／類翰林／類南一」是平台依課本編排的課程。 |
| 專案設計建議 | 以下的故事任務、分層和單本內容量均為設計建議，不是課綱規定。 |

注意：國語「第一學習階段」包含小一、小二，不能直接當作小一上門檻；例如識字量的階段目標不應拿來要求尚未入學的孩子。數學的 `N-1-*` 是一年級學習內容，`n-Ⅰ-*` 則是第一學習階段表現。英語領綱從第二學習階段（小三、小四）起列學習表現，小一英語在此作為啟蒙／彈性延伸。依據見 [官方來源 A1–A4](SOURCES.md#官方依據)。

## 3. 國語：小一上聯集主題庫

依 [國語課程計畫 C1–C3](SOURCES.md#國語版本資料) 收錄。下列不是教材課次順序；各版本出現較晚的項目也保留在主題庫，實際任務依孩子準備度選用。

| 主題 | 可選範圍 | 原創故事／練習做法 |
| --- | --- | --- |
| 聽與說 | 聽懂簡短敘述、輪流說話、問候、說出人物和動作。 | 聽大人念一句，點出正在幫忙的角色；看圖說發生什麼事。 |
| 注音 | 逐步接觸 37 個符號、聲調與拼讀，從聲音、圖片連結到文字。 | 一次挑少量已接觸的音做配對；不要求看懂所有注音才可通關。 |
| 識字與字形 | 生活常見字、字音字義連結、基本筆畫與筆順、簡單部件觀察。 | 圖與詞配對、找相同部件；正式選字時查該冊字表和字典。 |
| 詞語 | 動作詞、量詞、疊字、生活中的相反意思。 | 從情境分辨長／短、大／小；用「一隻、一個」描述眼前物品。 |
| 句子 | 誰做什麼、誰怎麼樣、簡單提問、以「也」補充同類動作。 | 先口說，再用圖卡拼出一句完整意思；不以打字作門檻。 |
| 標點 | 隨短句接觸句號、逗號、問號，理解停頓和提問。 | 聽兩句語氣，選出角色是在問問題或告訴別人事情。 |
| 閱讀理解 | 看圖找訊息、辨認人物／地點／事件、事件先後、說出簡單理由。 | 回顧兩到三張情節圖；答案必須能從剛看過的故事找到。 |

版本補充也保留：康軒計畫中的量詞、疊字和「也」句；翰林計畫中的相反詞與提問；南一計畫中的疑問詞、字形部件觀察。這些是本次查核到的例子，不宣稱為某版獨有，更不要求同一本故事全部加入。

注音沿用專案指定字型的預先渲染文字圖；多音字依當句語意查讀音。英語不以注音拼寫發音。正式課文、插圖或完整題庫不直接搬入本專案，故事與題目另行原創。

## 4. 數學：小一上聯集主題庫

以下合併 [三版本課程索引 M1–M3 與學校計畫 M4–M5](SOURCES.md#數學版本資料)。目前索引中三版的主題重疊很多，但單元順序及細項不同，全部保留，不以是否三版共有作篩選條件。

| 主題 | 小一上的內容範圍 | 故事任務示例／界線 |
| --- | --- | --- |
| 數與數量 | 先 1–5，再 6–10，逐步到 30；數量與數字符號連結。 | 為小動物準備 5 顆果實。數到 30 不代表要算 30 以內加減。 |
| 順序與比較 | 分辨「第幾個」和「幾個」，比較多、少、相同。 | 找隊伍第 3 隻動物；比較兩籃哪籃多。排列方向先說清楚。 |
| 分與合 | 10 以內實物分組與合併，逐步理解 0。 | 把 5 顆果實分到兩個盤子，承認不同分法。 |
| 加法 | 總和在 10 以內，由實物添加、合併連結算式。 | 2 顆加 3 顆，一顆顆數出共有多少；交換兩堆位置仍同樣多。 |
| 減法與應用 | 被減數在 10 以內，拿走、剩餘及簡單比較，含 0 的情境。 | 6 顆拿走 2 顆，畫面要真的少 2 顆；先理解再回答。 |
| 長度與空間比較 | 長短、高矮、厚薄、遠近，直線與曲線的觀察。 | 對齊起點比較木板，不因透視縮放造成錯誤。公分、公尺不列入本階段必學。 |
| 形狀與形體 | 常見平面形狀；從盒、罐、球等實物觀察、分類、堆疊與拼排。 | 用三角形和正方形拼屋子；平面圓形和球體要有所區別。 |
| 時間 | 生活事件先後、時間長短的感受、整點與半點。 | 按早晨事件排序；讀 3 點或 3 點半。不要求複雜經過時間計算。 |

例如南一索引將分合排在順序之前，康軒／翰林則有不同順序；形狀單元也有平面圖形或盒罐球等不同切入方式。本專案可都採用，無須依某一家課次順序。

官方一年級範圍包含 100 以內數與更完整的基本加減，但不把全年內容提前視為小一上已學會。也不以 `3 + □ = 8` 這類加數未知題作一年級正式練習；數學領綱將相關未知項題型留至後續年級。乘除、分數、小數、正式長度單位或多步驟文字計算，不放進小一上預設題池。依據見 [A2](SOURCES.md#官方依據)。

## 5. 英語：低年級啟蒙／彈性延伸

英語不設「全臺小一上統一必修清單」。先用 [低年級教材及影音 E1–E2](SOURCES.md#英語啟蒙資料)，保留廣泛主題供各本選用。下表的字詞與句子為專案建議池，不宣稱每校、每版一上都教這些內容。

| 主題池 | 可選內容例子 | 孩子如何參與 |
| --- | --- | --- |
| 日常招呼 | hello、goodbye、thank you、簡單自我介紹。 | 跟角色打招呼，願意時跟說；不強制麥克風辨識。 |
| 字母與聲音 | 逐步認識大小寫 A–Z 和常見字母音。 | 一次幾個字母，先聽辨與配對，不一次考完 26 個。 |
| 數字與顏色 | one–ten；red、blue、yellow 等。 | 聽聲音找相應圖像；顏色任務另有清楚形狀／名稱提示。 |
| 生活名詞 | 動物、身體、家庭、學用品、食物、玩具。 | 挑與當本情節相關的少量詞，不把整張單字表塞進故事。 |
| 動作指令 | look、listen、stop、go；熟悉後加入 left／right。 | 先示範動作再操作，保留看圖／中文協助。 |

先以聽懂、指認與願意回應為目標，之後再加認讀。不以拼字、文法選擇題、完整英文閱讀或語音辨識分數阻擋主線。未來製作教學音訊時，另確認發音、可重播、音量與授權；關閉聲音仍能完成故事。本次沒有新增音訊或程式。

## 6. 孩子尚未入學：建議的加入順序

以下是設計分層，不是入學能力檢定；不設定必須幾週完成。

| 層次 | 國語 | 數學 | 英語 |
| --- | --- | --- | --- |
| 先接觸 | 大人讀短句、看圖說話、跟一個指令。 | 點數 1–5、配對、比較長短／多少。 | 問候、模仿聲音、少量顏色或動物詞。 |
| 熟悉後 | 聲音與注音／常見字連結、兩到三張圖排序。 | 1–10、序數、分合、形狀。 | 少量字母、數字 1–5、簡單指令。 |
| 再擴充 | 短句理解、提問、標點與字形觀察。 | 數到 30、10 以內加減、整點半點。 | 數字到 10、更多生活詞與短句。 |

第三本的教育點可先從「先接觸」層選擇；目前沒有指定第三本主題。建議一本設一個主要教育點，再依情節加入一個輔助點；英語可少量選配，不要求每幕都考三科。

每個新概念先示範，再讓孩子操作；答錯給具體提示與重試，保留繼續冒險的方法。不要用限時識字或算術分數淘汰孩子；鏡頭／體感的成功也不能當作已掌握學科的證據。

## 7. 小一下與到小六的後續整理

小一下先保留待細化範圍：

- 國語：延續注音閱讀、生活識字、短文理解、詞句與口語表達；下次逐版核對第二冊，再決定新增字詞與句型。
- 數學：數到 100、版本稱為 18 或 20 以內的基本加減、二位數加減、錢幣、月曆、個別單位量長、圖形形體、分類紀錄。各題型與運算限制待一下專項整理，不直接併入一上。
- 英語：延續低年級啟蒙主題，依學習經驗加詞句；不自行假定全校同一進度。

小二之後再逐年逐學期增補；國語／數學以第一（小一至小二）、第二（小三至小四）、第三（小五至小六）學習階段銜接，英語從第二學習階段加入正式領綱對照。目前沒有完成小二至小六的教材聯集，不能先據此出題。

## 8. 以後每本故事的教育點交接

在故事概念階段填寫下表，和情節一起交使用者確認，再依既有 SOP 進行分支、圖片與工程。

| 欄位 | 應記錄的內容 |
| --- | --- |
| 學習範圍 | 年級／學期、啟蒙或已學後練習；對應本文件主題及來源。 |
| 主要與輔助教育點 | 孩子完成什麼可觀察的行為，例如數出五個物品。 |
| 前置經驗 | 需要已接觸哪些字音、數字或操作。不能只寫「小一程度」。 |
| 新字與新詞 | 本次新介紹、重複練習及僅出現在故事中的詞分開；查核注音。 |
| 題目條件 | 數值範圍、圖片物件數、可接受答案、多解情況與提示。 |
| 通關方式 | 示範、提示、重試、替代操作；不因閱讀／英語或裝置能力卡死。 |
| 試玩回饋 | 哪裡需大人協助、圖文是否清楚；據此調整，不先做排名或學力判定。 |

本文件只建立內容選用與審查方法，沒有新增課程系統、學力追蹤、存檔欄位或修改既有故事。
